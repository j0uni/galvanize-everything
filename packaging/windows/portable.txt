Galvanize Everything portable mode

While this file sits next to galvanize-everything.exe, Galvanize Everything keeps its settings, logs, projects
index and engine store in the GalvanizeEverythingData folder beside it, and writes nothing to %APPDATA%.
Copy the whole folder to move Galvanize Everything with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\galvanize-everything) instead.
